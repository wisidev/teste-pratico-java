# Teste Prático de Programação - Java

Projeto desenvolvido em Java puro para atender aos requisitos do teste prático.

## Estrutura

- `Pessoa.java`: classe base com nome e data de nascimento.
- `Funcionario.java`: herda de Pessoa e adiciona salário e função.
- `Principal.java`: executa os requisitos 3.1 a 3.12 do enunciado.

## Como executar

Com o JDK instalado:

```bash
cd src
javac -encoding UTF-8 Pessoa.java Funcionario.java Principal.java
java Principal
```

Não são necessárias bibliotecas externas.
